# Oasis Infobyte Web Development Internship

This repository contains the projects I completed during my **Web Development Internship at Oasis Infobyte**.

During the internship, I worked on three different tasks that helped me practice and improve my frontend development skills, starting with basic HTML and CSS and then moving into JavaScript-based functionality.

---

## 📌 Tasks Completed

### Task 1 — Verdant & Co. | Tea Brand Landing Page

**Verdant & Co.** is a responsive single-page website created for a fictional small-batch loose-leaf tea brand.

The main focus of this task was to build a visually appealing webpage while practicing HTML structure, CSS styling, layouts, and responsive design.

#### Key Features

* Sticky navigation bar
* Hero section with call-to-action
* Tea origins section
* Tea collection with four products
* Tea ritual and testimonial section
* Responsive layouts
* Hover effects and transitions
* Smooth scrolling
* Custom typography and color palette
* Mobile, tablet, and desktop support

#### Technologies

* HTML5
* CSS3
* Google Fonts — Fraunces & Work Sans

---

### Task 2 — Personal Portfolio Website

---

### Task 3 — Temperature Converter

For Task 3, I developed a **Temperature Converter** using HTML, CSS, and Vanilla JavaScript.

The application allows users to enter a temperature in **Celsius, Fahrenheit, or Kelvin** and instantly view the corresponding values in the other units.

I also included input validation to prevent invalid temperature values, including temperatures below absolute zero.

#### Key Features

* Celsius to Fahrenheit and Kelvin conversion
* Fahrenheit to Celsius and Kelvin conversion
* Kelvin to Celsius and Fahrenheit conversion
* Instant conversion using JavaScript
* Input validation
* Absolute-zero validation
* Responsive and simple user interface

#### Technologies

* HTML5
* CSS3
* JavaScript
